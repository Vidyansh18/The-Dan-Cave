# The Dan Cave

A retro-cyberpunk game-room website: a "gamer check" at the door, a scrolling origin story, a brick wall that explodes to reveal the title, and a menu of rooms (game collection, console wall, gallery, Snake arcade, about, settings).

Everything lives in `index.html`. The editable lists (soundtrack, story text, games, consoles, gallery, about) are in the `CONFIG` block at the top of the script.

Shortcuts: add `#menu` to the address to skip to the menu, or `#intro` to start at the story.
